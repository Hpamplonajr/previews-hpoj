# Previews HPOJ

Prévia pública dos sites gerados pela HPOJ Tech (Busca Leads).

O código do sistema fica em um repositório privado. Aqui só há HTML estático para o cliente abrir no celular.

## GitHub Pages

Ative em **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.

Exemplos:

- Site: `https://hpamplonajr.github.io/previews-hpoj/43-erico-pizza/`
- Landing: `https://hpamplonajr.github.io/previews-hpoj/landings/43-erico-pizza/`
